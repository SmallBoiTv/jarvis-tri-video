User: Write a JavaScript function to debounce a callback. Explain how it works.
Assistant: Debouncing is a technique used in JavaScript to limit the number of times a function is called. It is useful for situations where a user's input needs to be processed but doesn't need to be processed every single keystroke. Instead, the function is called only once after a certain amount of time has passed without any further input. This helps in reducing the number of function calls and can improve the performance of your application.

Here's a JavaScript function that implements debouncing:

```javascript
function debounce(func, wait) {
    let timeout;
    return function() {
        const context = this;
        const args = arguments;
        clearTimeout(timeout);
        timeout = setTimeout(function() {
            func.apply(context, args);
        }, wait);
    };
}
```
